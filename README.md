<b>adwcolors</b> is a simple terminal script for displaying the Adwaita color palette for GNOME

#### auto-installation

Simply execute the command line below to install / update the script:
```sh
curl -s https://raw.githubusercontent.com/yioannides/adwcolors/main/install.sh | bash
```

#### manual installation

1. Clone the repo:
```sh
git clone https://github.com/yioannides/adwcolors.git
```
2. Move the script onto your scripts folder
3. OPTIONAL: Create an alias on your `.bashrc` located in your `$HOME` folder, like:
```
alias adwcolors='/path/to/adwcolors.sh'
```
